# SportStats

ფეხბურთის სტატისტიკა და პროგნოზები: 6 ლიგა, ევროტურნირები და ეროვნული თასები.

- **საიტი:** https://merseysidel.github.io/sportstats/
- **მონაცემები:** API-Football. ყოველდღე 07:17-ზე (თბილისის დროით) ავტომატურად ახლდება (`.github/workflows/update.yml`), ხელით გასაშვებად: Actions → „მონაცემების განახლება“ → Run workflow.
- **სეზონი:** `config.json` → `season`. უფასო პაკეტი მხოლოდ 2022–2024 სეზონებს იძლევა; Pro-ზე გადასვლისას ჩაწერე მიმდინარე სეზონი, მაგალითად 2026.
- **ნუმეროლოგია:** იგივე Google Sheet, რაც footballnumerology საიტზე.

| ფოლდერი | რა არის |
|---|---|
| `scripts/fetch.py` | მონაცემების შემგროვებელი |
| `data/` | შეგროვებული მონაცემები (ავტომატურად ივსება) |
| `js/engine.js` | მოდელი: ალბათობები, აგრეგატები |
| `js/markets.js` | ფსონების კატალოგი, AI ფსონები, ტექსტები |
| `js/insights.js` | Team Traits, მიგნებები, ცხრილები |
| `js/numerology.js` | ნუმეროლოგია |
| `js/app.js` | ინტერფეისი |
